# Engineering

Skills for daily code work.

- **[engineering-manager](./engineering-manager/SKILL.md)** — Coordinate complex engineering work with specialist agents or human reviewers, validation gates, PR handling, and final independent audits.
- **[continuity](./continuity/SKILL.md)** — Learn, record, audit, and apply codebase patterns consistently across a repository.
- **[component-data-refactor](./component-data-refactor/SKILL.md)** — Review a focused React or React Native refactor, sketch data flow and component tree, then wait for approval before coding.
- **[source-parity](./source-parity/SKILL.md)** — Compare a source-of-truth implementation, design, API, or product surface against a target implementation, then produce and execute a narrow parity plan.
- **[repo-rule-mining](./repo-rule-mining/SKILL.md)** — Turn repeated code review findings into durable repository guardrails such as docs, skills, lint rules, ast-grep rules, tests, or CI checks.
