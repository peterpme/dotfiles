# Local Pi diagnostics

`traces/` holds local session captures. Everything in this directory except this file and `.gitignore` is ignored by git. The Pi **debugger** skill describes the session problem log. **reflect** reviews the active transcript separately.

For a scoped comment or test deletion probe, the Pi parent runs **no-comments** or **no-stupid-tests**. Launch through **spawn-subagent** using [the delegation contract](../docs/subagents.md), with the deletion reference and fixture paths in the brief. Inspect the diff and real test results. The old profile-based testbed is not part of the current workflow.
