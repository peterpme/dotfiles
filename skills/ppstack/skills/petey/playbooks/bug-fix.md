### Bug fix

1. Reproduce the defect on the matching product surface. Discover an installed Pi verification tool first. If none can reach the surface, state the missing capability and drive the closest real path yourself.
2. Build competing hypotheses. Use `how` for runtime flow and `why` for regression history. Instrument or bisect until runtime evidence confirms one mechanism.
3. Cross a function boundary only after `architect`. Give one fresh `worker` a standalone fix brief with the confirmed cause, scope, acceptance check, and same-surface repro. Do not select a model per run.
4. Inspect the diff. Revert lines whose hypothesis failed.
5. Run the original repro on the same surface. Add a focused regression test when it has a cheap stable seam.
6. Order evidence before fix in the delivery history when authorized, then run Opening a PR.

Reply with the failing evidence, root cause, fix, passing evidence, and any unavailable live check.
