# Productivity

General workflow tools, not code-specific.

- **[morning-recap](./morning-recap/SKILL.md)** — Summarize PRs merged in a GitHub repo over the last N hours, excluding ones you've touched, and rank what's worth reviewing.
- **[study-repo](./study-repo/SKILL.md)** — Clone a GitHub repo and set up an interactive study session for reading and analyzing the codebase.
